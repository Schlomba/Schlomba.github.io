transition-propertyWhat does it do?
Chooses which CSS property (or "all") will change gradually instead of instantly.
transition-durationWhat does it do?
Sets how long a transition takes to finish, in seconds (s) or milliseconds (ms).
transition-timing-functionWhat does it do?
Controls the speed curve of a transition, like ease, linear, ease-in, or ease-out.
transition-delayWhat does it do?
Makes the browser wait a set amount of time before a transition starts.
@keyframesWhat is it?
A rule that defines the steps of an animation, using from/to or percentages like 0%, 50%, 100%.
animation-iteration-countWhat does it do?
Sets how many times an animation plays. Use "infinite" to repeat forever.
animation-directionWhat does it do?
Decides whether an animation plays forward, backward, or alternates back and forth.
Transition vs. AnimationWhat's the difference?
A transition needs a trigger (like :hover) and goes from one state to another. An animation can run on its own with multiple steps.
